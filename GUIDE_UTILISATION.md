# Guide d'utilisation

## Pour l'animateur

### 1. Créer un webinaire

Depuis la page d'accueil, cliquez sur **Créer un webinaire** : donnez un
titre, un mot de passe (qui vous servira à vous reconnecter à la console
animateur depuis n'importe quel appareil), et choisissez deux réglages :

- **Modération des contributions** : si activée, chaque proposition d'un
  participant attend votre validation avant d'être visible des autres.
  Recommandé pour un public large ou un sujet sensible ; inutile pour un
  petit groupe de confiance.
- **Proposition de projets** : désactivez si vous démarrez directement
  avec un projet déjà défini (vous pouvez alors le pré-remplir dans le
  formulaire de création, champ "Pré-remplir un premier projet").

Vous obtenez un **code à 5 caractères** et trois liens : la page
participant, la console animateur, et l'écran de projection.

### 2. Avant le webinaire

Partagez le **code** ou le **QR code** (bouton "QR / Lien" dans la
console) avec les participants — ils peuvent rejoindre dès maintenant et
patienteront sur l'écran d'accueil. Affichez l'**écran de projection**
(`/w/{code}/projector`) sur le vidéoprojecteur de la salle : il montre le
QR code en attendant, puis bascule automatiquement sur les résultats en
direct à chaque étape.

### 3. Animer le webinaire

Dans l'onglet **Vue d'ensemble** de la console, un seul gros bouton vous
indique l'action suivante à chaque instant :

1. **Ouvrir la proposition de projets** → les participants soumettent
   leurs idées de projet.
2. **Clore les propositions et ouvrir le vote** → chacun vote pour le
   projet qu'il souhaite voir étudié.
3. **Retenir ce projet et démarrer** → le projet en tête (ou un autre, au
   choix, dans l'onglet **Projets**) devient le sujet de la consultation.
   Il démarre automatiquement avec les **6 axes de la Boussole de la
   Transition Écologique** (adaptation, atténuation, ressource en eau,
   biodiversité, pollution, économie circulaire), chacun identifié par sa
   couleur officielle — vous pouvez en ajouter d'autres, propres à ce
   projet, dans l'onglet **Consultation**.
4. Naviguez ensuite entre les **4 étapes** (impacts positifs → impacts
   négatifs → vote → améliorations) avec les boutons numérotés, et entre
   les axes avec "Axe précédent/suivant".
5. **Terminer le webinaire** quand la consultation est achevée : les
   participants voient un écran de remerciement, l'écran de projection
   affiche le résumé.

À tout moment :
- Dans le panneau **Consultation**, chaque contribution propose un bouton
  **🔄 Modérer** (remet ses votes à zéro sans supprimer le texte, utile en
  cas de votes suspects ou pour relancer le débat) et **Suppr.**
  (suppression définitive).
- L'onglet **Modération** liste les contributions en attente (si la
  modération préalable est activée dans les Paramètres — désactivée par
  défaut, auquel cas les contributions sont visibles immédiatement).
- L'onglet **Paramètres** permet de changer les réglages en cours de
  route, ou de réinitialiser le webinaire (les données restent
  exportables).
- Le bouton **Exporter (.zip)** télécharge un export CSV complet (projets,
  axes, contributions agrégées et votes individuels, votes de cotation).

## Pour les participants

1. Ouvrez le lien ou scannez le QR code communiqué par l'animateur (ou
   saisissez le code à 5 caractères sur la page d'accueil).
2. Renseignez votre nom si vous le souhaitez (facultatif — vous pouvez
   rester anonyme) en haut de la page.
3. Suivez le rythme donné par l'animateur : la page se met à jour
   automatiquement à chaque changement d'étape, inutile de recharger.
   - Pendant la **proposition de projets** : décrivez votre idée en
     quelques phrases.
   - Pendant le **vote de projet** : choisissez le projet que vous
     souhaitez voir étudié en priorité (un vote, modifiable tant que le
     vote est ouvert).
   - Pendant les étapes **impacts positifs / négatifs / améliorations** :
     proposez vos contributions, et votez (accord / désaccord / passer)
     sur celles des autres.
   - Pendant l'étape **vote** : donnez votre avis global
     (favorable / neutre / défavorable) sur le projet ou l'axe en cours.

Toutes les contributions et tous les résultats sont visibles de tous, en
direct.
